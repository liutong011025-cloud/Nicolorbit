# Nicolorbit Create PPT

Add the requested content to a copy of the supplied presentation. Learn the deck's established design before authoring and make the new slides or objects feel native to it.

## Inspect the deck and place the content

1. Inventory slide masters, layouts, recurring backgrounds, title styles, fonts, colors, spacing, image treatment, page numbers, citations, media, and section structure.
2. Render the full deck and select representative slides for title, content, comparison, evidence, activity, and section-divider patterns.
3. Decide where the requested material best supports the narrative. Insert it at the relevant conceptual point rather than appending it automatically.
4. Preserve existing animations, videos, hyperlinks, notes, charts, and editable objects.

## Write for slides

- Keep one clear message per slide. Split dense material across slides instead of shrinking it into a wall of text.
- Use concise headings and short bullets or callouts. Preserve necessary nuance in speaker notes when appropriate.
- Emphasize a small number of key words or phrases using the deck's established bold, size, or accent-color treatment.
- Keep ordinary body text regular weight. Maintain readable hierarchy and consistent alignment.
- Match the language, terminology, capitalization, and tone already used in the deck unless the user requests a change.

## Use visuals and evidence

- Avoid text-only content slides when a relevant photograph, diagram, chart, screenshot, or meaningful icon can communicate the idea better.
- Prefer authentic, high-resolution visuals that match the subject and presentation tone. Crop and position them consistently with the source deck.
- Do not add decorative images that compete with the message. Do not distort images or cover important content.
- Every factual claim, quotation, statistic, borrowed figure, and externally sourced visual must have a traceable source.
- Put compact source text at the bottom of the relevant slide in 10-point type unless the existing deck uses an equally legible equivalent. Include author or organization, year, short title when needed, and a working URL or DOI.
- Use official, primary, or authoritative sources where possible. Never invent a citation or attribute a claim to a source that does not support it.

## Match the original style

- Reuse existing slide masters and native layouts whenever they fit.
- Match background colors, title position, typefaces, margins, accent colors, line weights, corner styles, image masks, and footer placement from nearby reference slides.
- Create editable text, shapes, tables, and charts. Do not flatten completed slides into full-slide images.
- Keep page density and font sizes comparable to the deck. If content does not fit, edit or split it before reducing type substantially.

## Verify before delivery

1. Render every added or modified slide and inspect at full presentation size.
2. Fix overflow, collisions, awkward wrapping, low contrast, inconsistent emphasis, sparse balance, and source-footer clipping.
3. Check that each sourced item has the correct source on the same slide and that every link resolves to the intended publication or asset page.
4. Validate the PPTX package and confirm slide order, native editability, embedded media, hyperlinks, and animations remain intact.
5. Deliver a new PPTX and briefly identify inserted slide numbers or modified locations.
